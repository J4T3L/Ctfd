# CyberVault - CTF Challenge Handout

Welcome to **CyberVault Report Generator**!

## Challenge Description
CyberVault is an enterprise security audit generator. Can you find a way to break out of the template sandbox and read the flag located at `/flag.txt`?

## Local Setup
To run this challenge locally for debugging:

1. Make sure Docker and Docker Compose are installed.
2. Run:
   ```bash
   docker compose up --build
   ```
3. Access the web application at `http://localhost:8000`.

Good luck!
